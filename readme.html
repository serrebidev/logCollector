Log Collector and Serrebi Fixes

Log Collector

Adds Tools → Collect log errors… and the NVDA+Shift+L gesture to gather ERROR/CRITICAL entries and tracebacks from the NVDA logs, together with environment and add-on information, shown in a dialog you can copy or save.

NVDA+Shift+D toggles live debug-log capture: press once to start, once again to copy the captured debug output to the clipboard.

Serrebi Fixes

Applies targeted fixes for NVDA core bugs observed in the wild:

  • Guards review-mode position functions against a None navigator object.
  • Stops wxPython assertion failures from poisoning unrelated callbacks.
  • Guards the settings-panel refresh against a destroyed sizer.
  • Translates a failed cross-process content lookup in Firefox/Thunderbird into the "no caret" and "no descendant" signals core already handles, for every position rather than only the caret.
  • Keeps a focused control announced when its document cannot produce text at that instant, by speaking its name, role and state instead of nothing.
  • Reads an unloaded virtual buffer as empty, so closing or navigating a tab mid-say-all ends the reader cleanly instead of failing an RPC call.
  • Lets a table cell report its position on providers that implement only IAccessibleTable2, instead of aborting the announcement.
  • Demotes the logon-session comparison error logged when an application simply exits.
  • Stops phantom "WinError 0" failures from aborting braille display auto-detection scans.
  • Drops benign COM proxy registration leak warnings from UWP app hosts.
  • Suppresses "Malformed add-on scan results" spam caused by cached null scan data.

Each fix carries its full diagnosis, including the traceback that prompted it and why the chosen degradation is the one core already expects, in the comments at the top of globalPlugins/serrebiFixes.py.
